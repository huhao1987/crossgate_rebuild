# 魔力宝贝（cgmsv 25.11 / 客户端 4.06cn）协议实测笔记

来源：在本机 Wine 里运行原版 cgmsv.exe + 官方客户端 cg4.06cn.exe，服务端 `logPacket=1` 的封包日志
（`docs/captures/cgmsv_session_20261103.txt`），加上自写测试客户端（`/home/claude/proto/sess.py`）实测。
包头混淆表来自开源逆向项目 xgmsv（`docs/captures/optable_xgmsv.txt`：明文名 客户端发 服务端发），
与 cgmsv.exe 内的 72 个包头完全一致。

## 传输
- TCP，一行一个包，`\n` 结尾。字段用空格分隔，字段内空格写成 `\S`，换行写成 `\\n`，`\\z` 是子字段分隔符。
- 这个服务端**接受明文**（不加密也能通信）。原版的加密（64 进制 + 盐 + 条件取反 + LZW 压缩）已经移植成
  `/home/claude/proto/codec.cpp`（从 xgmsv 编译），解码服务端压缩包验证通过，联网模式需要时再接上。
- 数字：多数用 62 进制（字符表 `0-9a-zA-Z`，客户端 exe 里有这张表）；战斗包 `LYIm` 里用 16 进制；
  `nsY`(C)、`NI`(CA) 里坐标是 10 进制。

## 地图 / 行走
- `GmNM 0 <楼层62> <宽62> <高62> <x62> <y62> 0 0 0 0 -1 <令牌62>`：进图。**最后的令牌**行走时要带上。
- C→S `zA <x62> <y62> <方向串> <令牌62>`：行走。方向串每个字母一步：
  `a`=-y `b`=+x-y `c`=+x `d`=+x+y `e`=+y `f`=-x+y `g`=-x `h`=-x-y（大写 = 只转向）。
  起点必须是服务端认为的当前位置。没带令牌服务端**静默丢弃**（这是之前走不动的原因）。
- C→S `UUN 0 <楼层> x1 y1 x2 y2` → S→C `aBS ... <逗号分隔的地块编号62>`：地图数据。
- S→C `jmb 0 <楼层> x1 y1 x2 y2 <校验> <校验> 0`：地图校验（客户端发现和本地缓存不同就请求 UUN）。
- S→C `NI <id62>|x|y|<动作>|<方向>|...`：别人走动/动作；`nsY` 列出对象（类型|id|x|y|方向|形象|…|名字）。
- 换地图后令牌会变（实测 48→49）。

## 战斗（`B` = 服务端 `LYIm`、客户端 `Rg`）
- S→C `dAgg 1 <?>`：进入战斗（EN）。
- S→C `LYIm C|<效果标志>|<单位…>`：每个单位 12 段 `位置|名字|形象|?|等级|HP|最大HP|MP|最大MP|状态|?|?`，数字 16 进制；`C|20` 这种没有单位的表示战斗结束。
- S→C `LYIm A|<8000+?>|<回合>|`：要求下指令。
- C→S `Rg H|<目标16进制>` 普通攻击；（据 CGAssistant）`G` 防御、`E` 逃跑、`S|技能位|等级|目标` 技能、
  `I|道具位|目标` 用道具、`M|宠物` 换宠、`W|..` 宠物技能、`N` 什么都不做。
- S→C `LYIm M|...`：本回合的动作脚本（SKL/ACT 段），之后 `P|` `C|`（新状态）`A|`（下一回合）。
- 官方客户端的战斗画面是在当前地图上直接画（不切黑底），指令菜单在右上角，回合倒计时大数字在中间。

## 聊天 / 其他
- C→S `uSr <x62> <y62> P|<内容> <颜色> <范围> <大小>`（TK）；S→C `zdr <id> P|<名字>:\S<内容> ...`。
- `/warp 楼层 0 x y` 等是本服 Lua 管理员指令（已把测试账号加进 admin 列表），用于测试时传送。

## NPC 对话（实测）
- 站到 NPC 相邻格，发"只转向"的走路包 `zA x62 y62 <大写方向> 令牌` 面向 NPC，服务端就回 `BZ` 窗口。没有单独的"对话"封包（CGAssistant 也是用 TurnTo 跟 NPC 说话）。
- 窗口选项序号：协议从 **1** 数（类型 2 列表、类型 5 商店入口都一样；发 0 服务端不理）。

## 商店（WN 类型 5/6/7，实测 药剂师波洛姆 1112 16,35）
- 类型 5 入口：`头像|NPC名|话|3`，回 `xD x y seq npc 0 1`=买、`2`=卖。
- 类型 6 买列表：`头像|名|话|钱不够的话|背包满的话|` + 每件 6 段 `名字|图像|单价|说明|?|一次最多几个`。
  买：`xD x y seq npc 0 序号\\z数量\\z[序号\\z数量\\z…]`（序号从 0），成功后回 aPc（金钱）+ rU（新格子）。
- 类型 7 卖列表：`头像|名|话|` + 每件 10 段 `名字|数量|图像|价格?|格子|0||说明|0|堆叠上限`。
  卖的回包格式**还没对上**（试过 `格子\\z数量`、序号、带结尾分隔符，服务端都只回"请保重"）。待用官方客户端卖一次，看 cgmsv/log/packet_*.txt 里的 [Recv]。

## 人物状态 CP（aPc）
- 第一个字段 = 位掩码（62 进制，可带负号 = 32 位有符号）。`1` = 完整，后面依次第 1…31 项；否则每个置位的第 i 位跟一个值。
- 用 GM 脚本改值对照：1 HP、2 最大HP、3 MP、4 最大MP、5–9 体力/力量/强度/速度/魔法、15 等级、27 金钱、29 名字。
  例：`aPc 95aa4|10000|`（第 27 位 = 金钱）。

## 道具 I（rU）
- 每格 14 段：`格子|名字|?|说明|图像|?|?|?|?|?|道具编号|?|数量|`（最后一段空）。一行可以有多格。
- 格子 0–7 装备栏（7 = 水晶），8–27 背包。名字为空 = 清空该格。数量 0 = 不可堆叠单件。

## 昼夜调色板（实测）
- 官方客户端在法兰城挂约 4 小时、每分钟截图判别调色板：一天 = 现实 7200 秒。
- 以 (服务端 unix 时间 − 95) mod 7200：0–2700 白天 palet_00，2700–3600 黄昏 01，3600–6300 夜晚 02，6300–7200 清晨 03。177 个采样全部吻合。
- 服务端时间来自登录后的 LI（PudO）包第 2 段（62 进制 unix 秒）。室内地图（地图名 "名字|N"）用固定调色板 N。

## BZ 窗口的按钮掩码、xD 的按钮值都是 62 进制（官方抓包，2026-11-04）

- `BZ <类型> <按钮掩码> <序号> <NPC> <内容>`：类型和掩码都是 62 进制。是/否窗口掩码是 `c`（= 12 = 是 4 + 否 8），下一页是 `w`（= 32）。
  之前按十进制解析，`c`、`w` 解析失败成 0，界面只显示"确定"。
- 回复 `xD x y 序号 NPC <按钮> <数据>`：按钮值同样是 62 进制。官方按"下一页"发 `w`；发 `32` 服务端不理（这就是多页对话卡住的原因）。
  1/2/4/8 十进制和 62 进制写法一样，所以确定/取消/是/否之前碰巧能用。
- 官方对话框布局（960×720）：窗口 448×240，水平居中、比中心高 12；文字按 GBK 字节等宽排，每字节 8.5 像素，每行最多 46 字节（47 就换行），行距 19；
  服务端文字开头的 `\n\n` 是两行空行；n 个按钮中心在宽度的 (i+1)/(n+1)。

### 选择窗口、按钮、聊天（官方客户端对照实测，见习封印师鲁德 / 马葛道尔）
- 选择窗口（BZ 类型 2）的文字第一行只有一个数字 N：这一行在内、选项前共 N 行；这一行不显示。例：`4\n\n你知道…?\n要封印…\n什么是宠物档案卡?\n什么是封印卡?` → 正文 3 行（第 1 行空），选项 2 个。
- 选选项：xD 的按钮字段 0、选项字段从 1 数。
- 窗口按钮是黄色 (255,255,0) 格子字，不是图片：`确 定` `取 消`（中间半角空格）、`是` `否`、`上一页` `下一页`；以 w·(i+1)/(n+1) 为中心，字顶在窗口顶 +209（240 高时）。
- 悬停框：纯绿 (0,255,0)、2px。选项框 x 13 … w-15、从字原点上 3px、高 17；按钮框比字左 2.5px、宽 字宽+2、高 18。
- 聊天/系统消息 TK 包 `zdr 对象号 P|文字 颜色 字号`：颜色 0 白、1 青（0,255,255）；系统消息对象号 -1。文字里 `\S` 空格、`\\c` 逗号、`\\n` 换行。
- 聊天栏在左下：默认显示 2 行（系统设定 → 聊天设定 → 显示行数），最新一行字顶 y=654，行距 18，字左 x=11。
- NPC 类型：TownPeople 对话 = 服务端发一条聊天"名字: 话"（第 24 列几个 msg 编号随机一个）；Billboard 对话无回应；Windowman 走 WM 脚本（见 server WindowmanScript）。

## 技能 / 宠物（2026-11-04 实测：官方客户端 + 服务端日志 + 自写客户端发包）
- S→C `cNE`（CS）人物技能：每个 11 段 `栏位|技能编号|名字|等级|经验|?|升级经验|占用栏数|?|?|顺序`；登录发全部 20 栏，变化时只发一栏。名字空 = 空栏。
- S→C `Rspn <技能栏> 名字|说明|MP|?|招式编号|?|…`（CT）：该技能的各招，每招 6 段（例 `气功弹LV1|以赤手空拳来攻击敌人|2|1|4213|1`）。
- S→C `UU`（CP2）第 17 项 = 技能栏总数（10）。官方技能窗口"剩余技能栏 = 总数 − 各技能占用栏数之和"。
- S→C `IsSy <宠物栏> <掩码>|…`（KP）：掩码规则同 CP。1 形象 2 等级 3 HP 4 最大HP 5 MP 6 最大MP 7 经验 8 升级经验 10 攻击 11 防御 12 敏捷 13 精神 14 回复 15 忠诚 22 名字 23 昵称 **24 状态**。
- S→C `AU <宠物栏> 1|…`（KP2，宠物基础点数）；`OBee <宠物栏> 序号|招式编号|名字|说明|MP|?|?|?|…`（PT，宠物技能，每招 8 段）。
- C→S `LKQy s0 s1 s2 s3 s4`（KS）设宠物状态，**必须 5 个**（每个宠物栏一个）：0 休息 1 待命 2 战斗 3 散步（出现在地图上）。
  只发 2 个时服务端会改状态、回 `IsSy n 18owg|状态|`（第 24 位），但不设人物的"战宠"字段，宠物不会出战。同时两只设 2 → 服务端不理。
- 战斗 `A|<标志16进制>|<回合>`：没带宠物 8000（指令1）→ 8001（指令2）；带宠物 400（玩家指令）→ 420（宠物指令，0x20）→ 421（都下完）。
  宠物全设待命后服务端仍可能发 400/420（战宠字段没清），此时战场上没有宠物，服务端自己跳过——客户端按"人物位置 − 5 有没有我方单位"判断。
- C→S 技能 `Rg S|技能栏|第几招|目标`（气功弹 LV1 打 A 号 = `S|1|0|A`）；宠物 `Rg W|宠物技能序号|目标`（`W|0|A`）。
- 带宠物时人物在 5 号位、宠物在 0 号位。动作脚本里人和宠物一起打会出现 `CMB|d目标|a行动者|f..|d伤害|…`（合击）。
- 官方界面：指令面板背景 22676 指令1 / 22677 指令2 / 22650 玩家指令（带宠物）/ 22680 宠物指令（在 685,4）；指令2 里技能/物品/宠物/武器/位置变灰（22659/22662/22665/22668/22671）。
  技能窗口 22700 (688,111)，每行 22703 (695,164+24i)；招式窗口 22701；取消 22681/2，技能表 22683/4。底部主菜单 22550（640×24，鼠标到最底下 24 像素出现），单个按钮高亮 22551–22557。

## 战斗：宠物 / 武器 / 位置、卖东西（2026-11-04 官方客户端实测）
- 战斗里"宠物"按钮：更换宠物窗口 22720。叫出 `Rg M|宠物栏`（例 `M|1`），收回 `Rg M|FF`。用掉人物本回合的一个行动（叫出后面板变指令2；收回后服务端发 A|401 要宠物指令）。
- 战斗里"武器"按钮：更换武器窗口 22736（背包 20 格，非武器盖红叉 22738，盾不打叉）。换上 `Rg Q|格子16进制|`（例 `Q|15|`），解除武装 `Rg Q|FF|`。
- 战斗里"位置"按钮：没有窗口，直接 `Rg P`（人物与宠物前后排对调）。
- A| 标志低位：0x01 = 人物用宠物指令下完、等宠物（401）；0x20 = 人物下完、等宠物（420）；0x21 = 都下完（421）。

## 战斗动作号与魔法特效（2026-11 对照数据/官方 exe 查证）

### 人物/怪物动画的动作号（逐帧画出来核对）
0 站立、1 走路、2 攻击、3 受伤、5 施法（举武器较长）、6 举武器、7 被击飞、8 防御、9/11 躺地、10 倒下、

### 招式编号
服务端 tech.txt 第 4 列 = 招式编号 = 技能编号×100 + 等级−1（气功弹LV1=400 属技能 4，陨石LV1=1900 属技能 19，补血LV1=6100 属技能 61）。
宠物版从 16 开始（1916 = 宠物陨石 LV1）。Rspn 每招第 5 段（4213、4189…）**不是**招式编号。
战斗动画 SKL|s<hex> 里的就是招式编号。
